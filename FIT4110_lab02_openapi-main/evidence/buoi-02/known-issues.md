# Known Issues — Lab 02

Ghi các lỗi còn tồn tại nếu chưa xử lý xong.

| Lỗi | Ảnh hưởng | Cách xử lý dự kiến | Người phụ trách |
|---|---|---|---|
| Không có repository Git trong folder hiện tại | Không thể sinh git log tự động bằng script | Nếu cần, sao chép git log từ repo gốc hoặc khởi tạo repo Git trong workspace | Sinh viên |
| Chưa có ảnh mock server, chỉ có file log văn bản | Minh chứng mock server được lưu dưới dạng log văn bản thay vì ảnh chụp màn hình | Nếu cần, tạo thêm ảnh chụp Terminal/PowerShell từ các lệnh curl đã dùng | Sinh viên |
